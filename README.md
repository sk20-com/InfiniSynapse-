# 三只牛 · 小班运营雷达

> **InfiniSynapse Vibe Coding Hackathon 2026 · Education 赛道** 参赛作品
> 在线体验：<https://sk20-com.github.io/InfiniSynapse-/>

把 35 名学员的名册、8 周出勤、3 门课程与测评结果，压成一屏可读的排序：**今天先联系谁、哪门课先改、师资与座位怎么分**。

---

## 一、场景：谁 · 什么周期 · 要回答什么

**牛一老师**，一家培训机构 A / B / C 三个小班的教务负责人，现在带到 **第 8 周**。

她要回答的一句话问题是：

> **哪几位学员正在流失？今天先联系谁？**

打开第一屏就能看到这个人和这个问题，以及当前数据算出来的 **流失风险 TOP 3**。

---

## 二、数据链路（输入进 → 决定出）

```
招生在册名册 + 8 周出勤 + 完课率 + 3 门课程 + 测评结果
        ↓  风险分（口径公开，可手算复核）
   学员排序 / 课程排序
        ↓  带数字的理由码
   行动清单：联系谁 · 改哪门课 · 师资与座位怎么分
        ↓
   InfiniSynapse 深度建议（SSE 流式）
```

**风险分公式**（写在页面上，评委可复核）：

```
风险分 = 0.4 ×（100 − 出勤率）
       + 0.35 ×（100 − 完课率）
       + 0.25 ×（100 − 测评分）
近 3 周出勤比 8 周均值低 ≥5pt 再加 5；≥10pt 再加 10；封顶 100
```

**理由码**：每条建议旁边都挂着带数字的标签，例如 `出勤 52%` `完课 48%` `8周 −10pt`，结论能一路回溯到数据台的某个单元格。

- 所有数字都能在数据台原地改写为真实数据，图表与建议实时联动

## 五、技术实现

- **单文件 `index.html`**，纯 HTML + CSS + JS，零构建、零后端
- **InfiniSynapse Server API**
  - `GET /api/ai/events?connId=` — SSE 事件流（`message.add / partial / update`、`state.ready`、`notification`、`heartbeat`）
  - `POST /api/ai/message` — `type=newTask` 建任务；`type=askResponse` 回 Agent 提问；任务可 `cancelTask`
  - 鉴权 `Authorization: Bearer <API Key>`
  - 分片按 `ts` 归并（覆盖式更新 + 按 ts 顺序拼接），不会重复或丢字
  - 错误码翻译：`1101 / 1105` → Key 无效或过期；`500 busy` → 自动重试一次；网络失败 → 提示换节点
- **API Key** 只写入本机 `localStorage`（`sanniu_ai_key_v1`），不随页面发布、不写入代码
- **Chart.js 4.4.1**（CDN），加载失败或离线时自动降级到内置 Canvas 渲染，图形与数字不丢
- **响应式**：桌面双栏 / 平板收窄 / 手机单列（表格在手机上变卡片）

## 六、如何使用真 AI

1. 到 <https://app.infinisynapse.com/ai/apikey> 创建 API Key
2. 打开页面 → **AI 分析** → 粘贴 Key → **保存** → **测试连接**（显示「连接正常 · XXXms · Key 可用」即通）
3. 点 **用 InfiniSynapse 分析**，结论会流式输出并自动同步到行动清单页

> 没有 Key 时，点 **「无 Key 演示（规则引擎）」** 也能看到同样结构的三段结论，页面会明确标注来源不是 AI，保证演示不中断。

支持海外 `app.infinisynapse.com` 与国内 `app.infinisynapse.cn` 两个节点，可在页面上切换。

## 七、如果 AI 引擎繁忙（演示预案）

高峰期 `/api/ai/*` 可能返回：

```json
{"code": 500, "message": "Server is busy, please try again later"}
```

这是 **InfiniSynapse 平台侧 AI 资源池的状态**，不是 Key 失效、也不是本作品的代码问题 —— 同一账号下 `/api/ai_task/*` 仍然返回 `200`，鉴权也正常通过。

### 页面在这种情况下会做什么

1. 明确显示「**AI 引擎繁忙 · 平台侧原因，不是你操作错了**」，并附「**再试一次**」按钮
2. 自动用**本地规则引擎**在行动清单页填出同结构的三段结论，并标注「本地规则引擎 · 非 AI」
3. 主输出的错误框里直接写明「下方已用规则引擎给出同结构结论，可直接演示」

所以**任何时刻打开都能看到完整的数据链路**：输入可见可改 → 风险分 → 排序 → 图表 → 行动清单。AI 是最后一层增强，不是链路的前置条件。

### 服务不可用时的推荐演示顺序

| 步骤 | 操作 | 看点 |
|---|---|---|
| ① | 封面 | 牛一老师 + 第 8 周 + 谁在流失、先联系谁 + TOP 3 |
| ② | 数据台，改一个数字 | 风险分 / 排序 / 图表 / 行动清单同时重排 |
| ③ | 可视化 | 三张图 + 每张图下面的「读法」结论 |
| ④ | AI 分析 → 测试连接 | 显示「引擎繁忙」就点「无 Key 演示（规则引擎）」 |
| ⑤ | 行动清单 | 三段结论 + 带数字的理由码 |

### 旁白（可直接照念）

> InfiniSynapse 的 AI 引擎此刻正在限流，我先用同一套公开口径的规则引擎演示完整闭环 —— 改一个数字，排序、图表、行动清单会一起重排。AI 接上线后，走的是同一份 prompt、同一个三段结构。

### 三种失败的区分方式

| 页面提示 | 含义 | 处理 |
|---|---|---|
| **引擎繁忙**（蓝字） | Key 已通过鉴权，平台 AI 资源池繁忙 | 隔几分钟点「再试一次」，或把节点切到国内 `.cn` |
| **Key 无效或已过期（code 1101）** | Key 错误或已过期 | 到 <https://app.infinisynapse.com/ai/apikey> 重新生成 |
| **连不上（网络错误）** | 本地网络 / 跨域 / 节点不可达 | 检查网络，切换节点重试 |

> 想确认到底哪一步出问题，可以打开浏览器 F12 → Network，看 `/api/ai/events` 与 `/api/ai/message` 的响应体 —— 若是 `code:500 Server is busy` 即为平台侧，与作品无关。
