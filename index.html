    HOW IT WORKS闭环

    输入进 → 决定出

    这一页说清四件事：数据从哪来、技术怎么接、合成数据怎么标、评审的三个维度在这份作品里落在哪。

    ✦数据路径

    • 输入：招生在册名册 / 8 周出勤 / 完课率 / 3 门课程 / 测评结果
    • 计算：风险分 + 近 3 周趋势 → 学员与课程的排序
    • 决策：联系谁、改哪门课、师资与座位怎么分
    • 每个结论旁边都有带数字的理由码，可回溯到单元格
    数据录入→ 可视化→ AI 分析→ 行动清单

    ✦技术集成

    • 纯 HTML + CSS + JS 单文件，零构建、零后端
    • InfiniSynapse：GET /api/ai/events（SSE）+ POST /api/ai/message（type=newTask）+ Bearer
    • API Key 只写入本机 localStorage（sanniu_ai_key_v1），不随页面发布
    • Chart.js 走 CDN，失败自动降级到内置 Canvas 渲染
    • 响应式：桌面双栏 / 平板收窄 / 手机单列，表格在手机变卡片

    ✦数据声明（重要）

    • 页面里 3 个班、35 名学员、8 周出勤、课程与测评全部是 SYNTHETIC 合成数据，为演示数据链路而生成
    • 不是真实机构数据，不含任何真实个人信息；学员姓名均为虚构
    • 所有数字都能在数据台原地改写为真实数据，图表与建议实时联动
    • 风险分口径写在数据台下方，评委可手算复核

    ✦对应评审三维度

    40%场景价值：首屏就写明"牛一老师 · 第 8 周 · 谁在流失、先联系谁"，并直接给出 TOP 3 与动作。
    35%技术完整性：输入字段可见可改 → 风险分 → Top 榜 → 图表 → 行动清单 → AI 建议，一条路走到底；改一个数字排序立刻变。
    25%创新：每条建议配"带数字的理由码"（如 出勤 58% 近3周 −6pt），排序不靠黑箱，可解释、可复核。

    ✦60 秒演示脚本

    • ① 停在封面：读一遍"牛一老师 + 本周问题"，指一下右侧 TOP 3
    • ② 进数据台：把 A 班某位学员的「出勤率」从 88 改成 50
    • ③ 看排序：TOP 榜、风险分、图表、行动清单同时重排
    • ④ 进 AI 页：无 Key 跑规则引擎（有 Key 跑 InfiniSynapse），结论回写行动清单

    ✦怎么打开

    • 直接双击这个 .html 文件即可运行，无需安装、无需服务器
    • 评委环境建议用 Chrome / Edge / Safari 最新版，手机端同样可用
    • 部署：把单个文件拖到 GitHub Pages / Netlify / Vercel 任意静态托管
    • 本页已适配 1440 桌面、1024 平板、390 手机三档宽度
